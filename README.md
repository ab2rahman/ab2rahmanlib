## 🌟 Featured Projects

### 📖 [HafalanQur-an](https://github.com/ab2rahman/HafalanQur-an)
> **Web App Hafalan Qur'an (Juz Amma) untuk Anak & Keluarga**
* **Live Demo**: [ab2rahman.github.io/HafalanQur-an](https://ab2rahman.github.io/HafalanQur-an/)
* **Deskripsi**: Web application bebas iklan dengan fitur *Play Range* ayat otomatis, pengulangan (repeat) per-ayat & per-surah, serta pengaturan tempo/speed audio tilawah Syaikh Minshawi.
* **Tech Stack**: HTML5, CSS3, JavaScript (ES6+), AlQuran API, Quran Foundation Audio CDN, GitHub Pages.
