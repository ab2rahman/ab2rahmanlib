## 🌟 Highlight Projects

### 📖 [HafalanQur-an](https://github.com/ab2rahman/HafalanQur-an)
* **Tech Stack**: `JavaScript`, `HTML5`, `CSS3`, `AlQuran API`, `Quran Foundation CDN`
* **Live Demo**: [ab2rahman.github.io/HafalanQur-an](https://ab2rahman.github.io/HafalanQur-an/)
* **Deskripsi**: Web app hafalan Qur'an (Juz Amma) anak bebas iklan dengan fitur *Play Range* ayat otomatis, repeat per-ayat & per-surah, serta pengaturan tempo audio Syaikh Minshawi.

### 🤖 [HandMasking](https://github.com/ab2rahman/HandMasking)
* **Tech Stack**: `Python`, `MediaPipe`, `OpenCV`, `PyQt5 / GUI`
* **Deskripsi**: Real-time hand tracking, gesture segmentation, dan auto-masking kamera berbasis Computer Vision & AI.
